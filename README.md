# DNA to protein translator


DNA to Protein Translator
A Python-based bioinformatics tool that converts DNA sequences into mRNA and translates mRNA codons into amino acid sequences using the standard genetic code.

About the Project
DNA contains the genetic instructions required for protein synthesis.

This project demonstrates the fundamental molecular biology processes of Transcription and Translation using Python.

It takes a DNA sequence as input, converts it into mRNA, divides the mRNA into codons, and translates those codons into their corresponding amino acids.
⚙️ Key Features
- DNA to mRNA transcription.
- Division of mRNA into three-nucleotide codons.
- Identification of the AUG start codon.
- Identification of stop codons (UAA, UAG, UGA).
- Translation of codons into amino acids.
- Generation of a protein sequence.
